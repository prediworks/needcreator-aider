# Annonce aux créateurs · Vidéo vitrine

À envoyer depuis Admin → « Messages aux inscrits », public Créateurs, après le déploiement.

**Objet** : Une vidéo, un prix, une marque qui l'achète : la vidéo vitrine

**Texte** (coller tel quel ; l'email commence déjà par « Bonjour Prénom, »)

```
Les marques reçoivent dix demandes de collaboration par jour et n'en lisent aucune. Ce qu'elles ouvrent, c'est une vidéo déjà tournée pour leur produit. C'est ce que nous vous proposons de faire, à votre prix.

- **Vidéo vitrine** : dans votre tableau de bord, choisissez une marque que nous démarchons et dont vous possédez un produit, tournez 15 à 30 secondes, fixez votre prix et les droits que vous cédez.
- **Nous faisons le reste** : la marque reçoit votre vidéo finie, en filigrane, avec un devis. Si elle lui plaît, elle l'achète en un clic ; vous êtes payé comme pour une mission, la version sans filigrane lui est livrée aussitôt.
- **Sinon, rien** : la vidéo reste à vous, dans votre portfolio.

Trois conseils : filmez le produit, pas les logos ni les contenus de la marque ; une accroche dans les trois premières secondes (nos accroches suggérées sont affichées pour chaque marque) ; un prix entre 80 et 150 € pour une première.

Tableau de bord → Vidéo vitrine.
```
